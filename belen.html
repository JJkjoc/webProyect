Mi sugerencia para el proyecto del equipo:

Estuve pensando en algunas ideas para el proyecto y podríamos hacer una página de una pastelería, un restaurante virtual y un creador de pizzas y sándwiches personalizados, donde se pueda elegir el tamaño (o la cantidad de cortes), los ingredientes y las salsas, y que el precio se calcule automáticamente.

Tecnologías: HTML5, CSS3, Bootstrap y JavaScript para el diseño y las funciones interactivas.

A dónde quiero llegar

  • Que el cliente arme su pedido y vea cómo queda antes de pedirlo.
  • Que el precio se calcule solo en cada cambio (cortes, ingredientes o salsas).
  • Que el equipo pueda juntar las tres ideas en una sola página.
